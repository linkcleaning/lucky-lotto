행운로또 개인정보처리방침

시행일: 2026년 10월 29일

요약
  • 행운로또는 어떤 개인정보도 수집·저장·전송하지 않습니다.
  • 회원가입, 로그인, 광고, 분석(통계) 도구가 없습니다.
  • 사용자가 입력한 내용은 모두 사용자의 휴대폰 안에만 저장됩니다.

1. 휴대폰 안에만 저장되는 정보

정보쓰는 곳
내가 넣은 숫자(생일·차량번호 등)번호 뽑기 가중치
생년월일(선택)재미로 보는 오늘의 운 계산
저장한 로또 번호·회차회차별 당첨 결과 확인

이 정보는 앱 개발자를 포함해 누구에게도 전송되지 않으며, 앱을 삭제하면 함께 지워집니다. 저장한 번호는 앱의 '내 번호' 화면에서 줄마다 직접 지울 수 있습니다.

2. 카메라

로또 용지의 QR 코드를 읽을 때만 카메라를 사용합니다. 촬영 화면은 QR 내용(회차·번호)을 읽는 데만 쓰이고 사진으로 저장하거나 외부로 보내지 않습니다. '사진에서 불러오기'로 고른 사진도 휴대폰 안에서만 읽습니다.

3. 알림

저장한 번호가 있는 회차의 추첨이 끝나면 결과 확인 알림을 보냅니다. 알림은 휴대폰 안에서 예약되며 서버를 거치지 않습니다. 휴대폰 설정에서 언제든 끌 수 있습니다.

4. 인터넷 사용

최신 당첨번호 목록(공개 자료)을 받기 위해 당첨번호 파일을 내려받습니다. 이때 사용자 정보는 보내지 않습니다. 파일을 제공하는 GitHub Pages는 일반적인 웹 서버처럼 접속 기록을 남길 수 있으며, 이는 GitHub 개인정보처리방침을 따릅니다.

5. 공유

'이 번호 보내기'를 누르면 휴대폰의 공유 화면이 열리며, 사용자가 고른 앱(카카오톡·문자 등)으로만 번호 문구가 전달됩니다.

6. 어린이

복권은 만 19세 이상만 구매할 수 있습니다. 이 앱은 복권을 판매하거나 구매를 대행하지 않습니다.

7. 안내

행운로또는 동행복권·복권위원회와 관련 없는 개인이 만든 앱입니다. 당첨 여부는 동행복권 공식 발표로 확인하세요. 도박 문제 상담: ☎ 1336 (한국도박문제예방치유원)
